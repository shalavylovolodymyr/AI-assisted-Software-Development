# UC-006 — Enter and leave the demo workspace

## Intent and actors
Welcome visitors to SIGNAL, explain its purpose and let them choose a fictional
user and log in without a password. All existing demo roles are supported.

## Flow and rules
1. Without an explicit saved session, show the welcome page on every route.
   A legacy automatically selected actor does not count as a login.
2. Load available users from the API; show loading, retryable errors and empty
   catalog feedback. Require a valid selection before enabling Log in.
3. Log in stores the selected demo actor locally and opens the requested route.
   Reload preserves the explicit session; an unknown actor returns to welcome.
4. The sidebar offers Log out in desktop, collapsed and mobile navigation.
   Logging out clears the actor, closes workspace dialogs/navigation, and returns
   to welcome. Browser Back cannot expose the workspace without logging in.
5. Appearance and display preferences survive logout. Demo identity remains
   attribution, not production authentication or an API security boundary.

## Deletion discovery
Expose labeled Delete actions for eligible issues/unfinished actions and labeled
Deleted items toggles for recovery. Retain UC-005 permissions, version checks,
confirmation, reversible deletion and immutable history.

## Validation
Component checks cover explicit entry, legacy/stale identities, reload and logout.
Real browser journeys cover welcome, selection, role homes, deep links, logout,
mobile/collapsed navigation and deletion/recovery against isolated PostgreSQL.
