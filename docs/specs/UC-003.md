# UC-003 — Reassess risk

## Intent
Measure risk change without destroying prior evaluations.
## Actors
Known selected demo assessor.
## Preconditions
Existing issue that is not RESOLVED; current issue version supplied.
## Inputs
Issue UUID, strict integer likelihood/impact 1–5, nonblank rationale, expected version.
## Flow
1. Lock issue and validate state, version and inputs.
2. Calculate score and severity in the domain.
3. Append a new assessment and risk-change audit event atomically.
4. Return chronological history; newest timestamp/UUID record is current risk.
## Alternative flows and errors
404 missing issue/actor; 422 invalid input; 409 stale version or resolved issue (reopen first).
## Postconditions and acceptance
Previous assessment IDs, values and timestamps are unchanged.
Risk matrix/distribution and issue current risk use the new evaluation.
## Tests
Unit: score boundaries/history preservation; integration/API: append ordering,
rollback and stale writes; E2E-002 checks matrix changes after reassessment.
## Non-functional
No assessment PATCH/DELETE endpoint; UTC timestamp generated by backend.
