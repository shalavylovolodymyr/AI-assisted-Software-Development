# ADR-001 — Modular monolith and clean boundaries

## Status
Proposed for human review. Implemented under the master prompt's explicit stack authorization.
## Context
Seven related entities and a five-minute local capstone demonstration need reliable transactions.
## Alternatives
Microservices, framework-centric CRUD, or a modular monolith.
## Decision
Use FastAPI with pure domain records and application ports; SQLAlchemy/PostgreSQL
implements persistence. Services own atomic workflow orchestration.
## Consequences
Simple delivery and testing, explicit mapping overhead, one deployable application.
